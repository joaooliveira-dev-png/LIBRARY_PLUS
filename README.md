# LibraryPlus

## Tecnologias utilizadas
- Java
- Swing (Interface gráfica)
- JDBC
- MySQL / MariaDB
- Git e GitHub

## Desenvolvedor
- João Vitor

## Objetivo do software
O sistema LibraryPlus tem como objetivo gerenciar o controle de empréstimos de livros, permitindo o cadastro de usuários, livros e o registro de empréstimos e devoluções.

## Funcionalidades
- Login de usuário
- Cadastro de usuários
- Cadastro de livros
- Controle de empréstimos
- Relatório de empréstimos
- Interface gráfica em Java Swing
